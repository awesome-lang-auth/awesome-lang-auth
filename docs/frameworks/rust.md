# Rust Integration — `awesome-rust-auth`

:::tip Official Rust backend library
For Rust backends, use [`awesome-rust-auth`](https://github.com/awesome-lang-auth/awesome-rust-auth).
:::

`awesome-rust-auth` is a framework-agnostic crate, with adapters for Axum, Actix-web and Warp, that brings the same auth model as awesome-node-auth to Rust. What it implements today, capability by capability, is tracked in its own [parity snapshot vs awesome-node-auth](https://github.com/awesome-lang-auth/awesome-rust-auth#parity-snapshot-vs-awesome-node-auth).
