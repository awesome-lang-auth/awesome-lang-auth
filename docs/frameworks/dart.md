# Dart Integration — `awesome-dart-auth`

:::tip Official Dart backend library
For Dart backends, use [`awesome-dart-auth`](https://github.com/awesome-lang-auth/awesome-dart-auth).
:::

`awesome-dart-auth` is a server-side library for Shelf and Dart Frog that brings the same auth model as awesome-node-auth to Dart. What it implements today, capability by capability, is tracked in its own [parity snapshot vs awesome-node-auth](https://github.com/awesome-lang-auth/awesome-dart-auth#parity-snapshot-vs-awesome-node-auth).
